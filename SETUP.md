# Как запустить планер

Инструкция для человека, который не занимается этим каждый день. Всё бесплатно, карта не нужна.
Порядок важен — иди сверху вниз.

Термины по ходу объясняются. Общее время — минут 20.

---

## Шаг 1. Создать бота в Telegram (3 минуты)

1. Открой Telegram, найди `@BotFather` (у него синяя галочка).
2. Отправь `/newbot`.
3. Он спросит имя — это то, что видно в шапке чата. Например: `Планер`.
4. Потом спросит username — он должен заканчиваться на `bot` и быть свободным. Например: `dz_planer_bot`.
5. В ответ придёт строка вида `8123456789:AAF...` — это **токен бота**. Не показывай его никому:
   у кого токен, тот управляет ботом.

Запиши: токен и username (без `@`).

**Privacy mode оставляем как есть.** По умолчанию бот не видит обычные сообщения группы — только те,
где его упомянули, ответили ему реплаем, или команды. Это именно то, что нам нужно.

## Шаг 2. Завести Cloudflare (5 минут)

1. Зайди на `dash.cloudflare.com/sign-up`, зарегистрируйся по почте. Карта не спрашивается.
2. Подтверди почту.

Cloudflare — это компания, на серверах которой будет жить бот. Бесплатный тариф даёт 100 000 запросов
в день; бот тратит около 1500.

## Шаг 3. Подключить компьютер к Cloudflare

В терминале, в папке проекта:

```bash
npx wrangler login
```

Откроется браузер, нажми «Allow». `wrangler` — это программа Cloudflare для управления проектом
из командной строки.

## Шаг 4. Создать базу данных

```bash
npx wrangler d1 create tg-planner
```

В ответе будет строка вида:

```
database_id = "8f2c1a9e-..."
```

Скопируй этот id и вставь в файл `wrangler.toml` вместо `PLACEHOLDER_FILL_ON_DEPLOY`.

Теперь создай в базе таблицы:

```bash
npm run db:remote
```

D1 — это база данных Cloudflare, по сути SQLite в облаке. Там будут лежать дела.

## Шаг 5. Записать секреты

Секреты — это пароли, которые хранятся у Cloudflare и не попадают в код и в git.

Сначала сгенерируй две случайные строки (выполни дважды, запиши оба результата):

```bash
node -e "console.log(crypto.randomUUID())"
```

Затем по очереди:

```bash
npx wrangler secret put BOT_TOKEN        # токен из Шага 1
npx wrangler secret put BOT_USERNAME     # username бота без @, например dz_planer_bot
npx wrangler secret put WEBHOOK_SECRET   # первая случайная строка
npx wrangler secret put API_TOKEN        # вторая случайная строка
npx wrangler secret put ALLOWED_CHATS    # пока введи 0, заполним на Шаге 8
```

Каждая команда попросит ввести значение — вставляй и жми Enter.

## Шаг 6. Выложить бота

```bash
npm run deploy
```

В конце появится адрес вида `https://tg-planner.твой-аккаунт.workers.dev`. Запиши его.
Проверь: открой этот адрес в браузере — должно написать «tg-planner жив».

## Шаг 7. Подключить Telegram к боту

Webhook — это адрес, по которому Telegram будет сообщать боту о новых сообщениях.

```bash
BOT_TOKEN=твой_токен WEBHOOK_SECRET=твой_секрет WORKER_URL=https://tg-planner.аккаунт.workers.dev npm run webhook
```

Ответ должен быть: `{"ok":true,"result":true,"description":"Webhook was set"}`

## Шаг 8. Узнать id чата и разрешить его

1. Создай тестовую группу в Telegram (можно с одним собой), добавь туда бота.
2. Отправь в группу `/день`.
3. В терминале запусти просмотр логов:

```bash
npx wrangler tail
```

4. Снова отправь `/день`. В логах появится строка с числом вида `-1001234567890` — это **chat_id**.
   У групп он отрицательный, это нормально.
5. Запиши его в секрет:

```bash
npx wrangler secret put ALLOWED_CHATS
```

Если чатов несколько (тестовый и рабочий) — вводи через запятую, без пробелов:
`-1001234567890,-1009876543210`

6. Передеплой: `npm run deploy`

Теперь бот отвечает только в разрешённых чатах, посторонние идут лесом.

## Шаг 9. Настроить добавление дел из Claude Code

Создай в папке проекта файл `.env.local` (он в `.gitignore`, в git не попадёт):

```
WORKER_URL=https://tg-planner.аккаунт.workers.dev
API_TOKEN=вторая случайная строка из Шага 5
```

Проверь:

```bash
npm run add -- "завтра в 15 проверить планер"
npm run list -- week
```

Первая команда создаст дело и покажет карточку в чате, вторая выведет список в консоли.
После этого Claude Code сможет класть дела в общий список сам.

## Как пользоваться

**Добавить дело:** упомяни бота в чате или ответь реплаем на его сообщение.

```
@dz_planer_bot завтра в 15:00 к врачу
@dz_planer_bot каждый вторник вынести мусор
@dz_planer_bot Жень, купи корм коту
@dz_planer_bot через 2 часа выключить духовку
```

**Команды:**

| Команда | Что делает |
|---|---|
| `/день` | дела на сегодня |
| `/завтра` | дела на завтра |
| `/неделя` | расписание на 7 дней |
| `/мои` | только твои дела |
| `/все` | дела без срока |
| `/настройки` | время дайджеста и напоминаний |
| `/help` | подсказка |

**Кнопки под делом:** «Готово», «Перенести», «Удалить», а также назначение на Даню, Женю или обоих.

## Если что-то сломалось

**Бот молчит.** Проверь, дошёл ли до него запрос:

```bash
npx wrangler tail
```

Пиши в чат и смотри, появляются ли строки. Если пусто — сбился вебхук, повтори Шаг 7.

**Проверить, что Telegram знает адрес бота:**

```bash
curl "https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo"
```

В ответе смотри поле `last_error_message` — там будет причина, если Telegram не может достучаться.

**Посмотреть, что лежит в базе:**

```bash
npx wrangler d1 execute tg-planner --remote --command "SELECT id, title, due_at, status FROM tasks ORDER BY id DESC LIMIT 20"
```

**Напоминания не приходят.** Убедись, что cron живёт: в панели Cloudflare → Workers → tg-planner →
Settings → Trigger Events должен быть `* * * * *`. И проверь, что у дела вообще проставлен срок:
командой выше посмотри колонку `due_at`.

**Обновить бота после правок кода:**

```bash
npm test && npm run deploy
```

Сначала тесты, потом деплой. Если тесты красные — деплоить нельзя.
